# LinQ VAL デモシナリオ（v24-pwa）

## 対象
- VC / 投資家向けプレゼンテーション
- 病院関係者（医事課・カテ室スタッフ）向けデモ
- 顧客ヒアリング時の実演

---

## 事前準備
1. スマートフォンまたはPC のブラウザで `index.html` を開く
2. 初回：職種選択画面で「🎯 デモデータ投入」ボタンをタップ → 18件のサンプル実施記録が投入される

---

## シナリオ1: 核心価値「ズレの発見」（医事課フロー / 3分）

### ストーリー
> 「手術で使った医材と、実際に請求されているUKEコードにズレがある。LinQ VALはそれを自動検出します」

### 操作手順
1. **職種選択** → 「🧾 医事」をタップ
2. **「🔍 UKE突合」** をタップ
3. **UKE突合画面が表示される**
   - 👉 ポイント：マッチ率、未マッチ件数、金額差がひと目でわかる
   - 👉 ポイント：未マッチ材料（赤色ハイライト）→ 「これが請求漏れの候補です」
   - 👉 ポイント：マッチ済み材料（緑色）→ 「これは正しく紐付いています」
4. **「⬇ UKE突合CSV出力」** をタップ → CSVがダウンロードされることを見せる

### キーメッセージ
- 「従来は月末に手作業で突合していた → LinQ VALならリアルタイムで検出」
- 「1件あたりの材料価格は数万〜数百万円。1件の請求漏れが病院経営に直結」

---

## シナリオ2: 実施記録の全体像（ダッシュボード / 2分）

### ストーリー
> 「どの材料がどれだけ使われているか。コスト構造は。LinQ VALで一元管理」

### 操作手順
1. **医事ホーム** → 「📊 ダッシュボード」をタップ
2. **ダッシュボード画面が表示される**
   - 👉 全件数・承認済み・承認待ちの件数
   - 👉 償還価格累計（総額）
   - 👉 材料使用ランキングTOP10（棒グラフ）
   - 👉 材料コストランキングTOP10
   - 👉 手技別件数
   - 👉 承認医師別件数
   - 👉 日別実施件数（直近14日のトレンド）

### キーメッセージ
- 「経営層はこのダッシュボードで病院のコスト構造を把握」
- 「高額材料の使用傾向を見て、在庫管理や購買交渉に活用」

## シナリオ3: スキャン → 承認の完全フロー（実施入力 + 医師 / 5分）

### ストーリー
> 「手術中のリアルタイム記録から、医師承認まで。紙やExcelは不要」

### 操作手順

#### パート1: 実施入力（カテ室スタッフ）
1. **職種選択** → 「📶 実施入力」
2. **「📶 スキャン」** をタップ
3. **Step 1**: 入力者を選択（例：看護師A）
4. **Step 2**: 患者を選択（例：PT-2026-0001 山田太郎）
5. **Step 3**: 手技を選択（例：PCI）
   - 👉 ポイント：⭐マークの「おすすめ手技」が自動表示される
6. **Step 4**: バーコードスキャン
   - スマホカメラでバーコードを読み取る（デモ用にバーコード画像を用意）
   - 読み取り成功 → トーストで材料名と価格が表示
   - 👉 ポイント：「JAN13/GTIN14を自動判別し、30万件の辞書から瞬時に検索」
7. **Step 5**: 確定 → 承認者選択（医師を選択） → 依頼送信

#### パート2: 医師承認
1. **職種変更** → 「👨‍⚕️ 医師」
2. ログイン → 承認画面
3. 承認待ちリストに先ほどの記録が表示
4. コメント入力 → 承認ボタン

### キーメッセージ
- 「手書き → 後でExcel入力 → 月末突合 のプロセスが、スキャン → 即時記録 → 即時承認 に」
- 「医師が必要な情報を確認した上で承認。監査トレイルも自動記録」

## シナリオ4: PWA体験（全職種 / 1分）

### 操作手順（Android Chrome）
1. ブラウザで開く → アドレスバーに「インストール」アイコンが表示
2. 「ホーム画面に追加」→ アプリアイコンが追加される
3. ホーム画面から起動 → フルスクリーンでアプリとして動作

### キーメッセージ
- 「ネイティブアプリのインストール不要。ブラウザだけで導入可能」
- 「IT部門の許可不要。既存のスマホ/タブレットですぐ使える」

## FAQ対策

| 質問 | 回答 |
|------|------|
| 「オフラインで動く？」 | 「Service Workerで対応済み。一度読み込めばオフラインでもスキャン・記録可能」 |
| 「既存の電子カルテとの連携は？」 | 「CSV出力で既存システムへの取り込みが可能。API連携はPhase 2で計画」 |
| 「セキュリティは？」 | 「現在はローカルストレージ。本番環境ではクラウドDB + HTTPS + 認証を実装予定」 |
| 「医材辞書のメンテナンスは？」 | 「厚労省の特材マスタを定期更新。自動インポートの仕組みを構築予定」 |
| 「導入コストは？」 | 「初期費用ゼロで試用可能。ブラウザだけで動くためハードウェア不要」 |
